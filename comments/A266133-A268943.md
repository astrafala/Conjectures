## A266133

OEIS entry: <https://oeis.org/A266133>  
Result obtained: **2 September 2026**  
Paper: [12606](../papers/12501-13000/12606-PROOF.pdf)

What the entry records as unsettled:

> Empirical recurrence of order 77 (see link above)

Proposed OEIS comment:

```
The recurrence in the linked file is correct, and it is the one below. Counting the arrays a row at a time gives a transfer matrix with 104 states, so a(n) satisfies a constant-coefficient linear recurrence of order at most that, and Berlekamp-Massey on exact terms returns the minimal one. Its order is 77, the order stated here, and so is the order of every tail. Any recurrence of that order the sequence satisfies therefore has the same characteristic polynomial, so it is this one. - _Adrian Perez Fontelles_, Sep 06 2026
```
