# archive

Superseded material, kept because the record should be complete rather than flattering.

- **`withdrawn/`** — papers withdrawn from the roster: duplicates, results that turned out to
  be already settled on the entry, and one whole family withdrawn on discovering that an
  existing engine performed the identical reduction. Each withdrawal is explained, dated, in
  [`../LEDGER.md`](../LEDGER.md).
- **`papers-new/`, `old-scan/`** — output from earlier versions of the pipeline, before the
  roster took its present form.

Nothing here is counted in the roster.
